## Ce que contient ce pack

## Catégorie 1 : Sourcing & Recherche de candidats (4 prompts)

### Prompt 1 — Générer une recherche booléenne LinkedIn Recruiter
```
Génère une requête booléenne LinkedIn pour trouver des [POSTE] avec [X] années d'expérience dans [SECTEUR], basés en [VILLE], ouverts aux opportunités. Inclus des variations de titres (français + anglais) et des compétences clés comme [COMPÉTENCE1], [COMPÉTENCE2], [COMPÉTENCE3]. Format: une seule ligne, prête à coller dans LinkedIn Recruiter.
```

### Prompt 2 — Message d'approche LinkedIn (cold outreach)
```
Rédige un message LinkedIn de 300 caractères maximum pour contacter un [POSTE] dans le secteur [SECTEUR]. Le ton doit être: direct, pas de bullshit corporate, une phrase d'accroche sur son parcours, la raison concrète pour laquelle je le contacte, et une question ouverte qui invite à répondre. Pas de "j'espère que vous allez bien". Pas d'émojis.
```

### Prompt 3 — Email de chasse (approche directe)
```
Écris un email de recrutement pour un [POSTE] chez [ENTREPRISE]. Structure: objet percutant (max 50 car), 1 phrase sur pourquoi son profil m'a arrêté (personnalisable), 3 bullets sur ce qui rend le poste unique (techno, impact, équipe), 1 phrase de closing avec call-to-action clair. Longueur max: 120 mots. Ton: humain, pas recruteur-boîte-d'intérim.
```

### Prompt 4 — Script d'appel téléphonique de sourcing
```
Rédige un script d'appel de 60 secondes pour contacter un candidat passif ([POSTE]). Structure: (1) qui je suis en 10 secondes, (2) pourquoi je l'appelle spécifiquement LUI en 15 secondes, (3) la proposition de valeur en 20 secondes, (4) question de closing en 15 secondes. Ajoute 3 réponses aux objections classiques ("je ne cherche pas", "envoyez-moi un email", "quel salaire?").
```

## Catégorie 2 : Analyse de CV & Matching (5 prompts)

### Prompt 5 — Analyse de CV vs fiche de poste (matching score)
```
Analyse ce CV et compare-le à la fiche de poste ci-dessous. Donne-moi: (1) un score de matching /100, (2) les 3 compétences qui matchent le mieux, (3) les 2 gaps les plus critiques, (4) une recommandation: GO / PEUT-ÊTRE / NO-GO avec 1 phrase de justification, (5) 3 questions à poser en entretien pour creuser les gaps.

CV: [COLLER CV]
POSTE: [COLLER DESCRIPTION POSTE]
```

### Prompt 6 — Extraction structurée d'un CV
```
Extrais de ce CV les informations suivantes au format JSON: années d'expérience totale, poste actuel (titre + entreprise + durée), 5 compétences techniques principales, 3 soft skills, formation (diplôme le plus élevé + école), langues parlées, prétentions salariales si mentionnées, mobilité géographique, disponibilité.

CV: [COLLER CV]
```

### Prompt 7 — Rédiger une synthèse candidat pour hiring manager
```
À partir de ce CV, rédige une synthèse en 5 bullets pour un hiring manager. Format: (1) profil en 1 phrase, (2) expérience la plus pertinente pour le poste, (3) compétence différenciante, (4) point d'attention ou risque, (5) recommandation: À VOIR / À REVOIR / NON. Maximum 150 mots.

CV: [COLLER CV]
POSTE CIBLÉ: [POSTE]
```

### Prompt 8 — Détecter les incohérences dans un CV
```
Analyse ce CV et signale toute incohérence ou anomalie potentielle: trous dans le CV (>6 mois non expliqués), chevauchement de dates, titre qui ne correspond pas aux missions décrites, diplôme introuvable, compétence déclarée sans expérience associée, progression de carrière illogique (baisse de séniorité). Pour chaque anomalie, indique le niveau de gravité (mineur / moyen / critique).

CV: [COLLER CV]
```

### Prompt 9 — Comparer 2 CV pour le même poste
```
Compare ces 2 CV pour le poste de [POSTE]. Format: tableau à 3 colonnes (Critère | Candidat A | Candidat B). Critères: années d'expérience, compétences techniques, soft skills, formation, salaire estimé, disponibilité, adéquation culturelle (si déductible), risque de rétention. En conclusion: quel candidat recommandes-tu et pourquoi en 3 phrases.

CV A: [COLLER]
CV B: [COLLER]
POSTE: [POSTE]
```

## Catégorie 3 : Entretiens & Évaluation (3 prompts)

### Prompt 10 — Générer une grille d'entretien structurée
```
Génère une grille d'entretien de 45 minutes pour un [POSTE]. Structure: (1) 5 minutes d'intro (icebreaker + déroulé), (2) 20 minutes de questions techniques (5 questions avec critères d'évaluation OUI/NON), (3) 15 minutes de questions comportementales (3 questions situationnelles type STAR), (4) 5 minutes de closing (questions du candidat + next steps). Inclus un système de notation /5 pour chaque question.
```

### Prompt 11 — Questions techniques par stack
```
Génère 10 questions techniques pour évaluer un [POSTE] avec la stack [STACK]. Niveau: intermédiaire à senior. Pour chaque question: (1) la question, (2) la réponse attendue (1-2 phrases), (3) un indicateur que le candidat ment ou survole. Les questions doivent couvrir: fondamentaux, pièges courants, design/architecture, debug, et une question ouverte "raconte-moi un problème complexe que tu as résolu".
```

### Prompt 12 — Débriefer un entretien (compte-rendu structuré)
```
À partir de mes notes d'entretien ci-dessous, génère un compte-rendu structuré: (1) résumé en 3 lignes, (2) points forts (3 bullets avec exemples concrets), (3) points faibles ou risques (3 bullets), (4) questions restées sans réponse, (5) feeling général (🟢 🟡 🔴), (6) recommandation (GO / 2ÈME ENTRETIEN / NO GO) avec justification. Maximum 200 mots.

MES NOTES: [COLLER NOTES]
POSTE: [POSTE]
```

## Catégorie 4 : Automatisation & Contenu (3 prompts)

### Prompt 13 — Rédiger une fiche de poste qui convertit
```
Rédige une fiche de poste pour un [POSTE] chez [ENTREPRISE] dans le secteur [SECTEUR]. Structure: (1) titre accrocheur, (2) 1 paragraphe sur l'entreprise et pourquoi c'est excitant (pas de blabla "leader depuis 1987"), (3) 5 missions concrètes (pas "participer à" mais "vous serez responsable de"), (4) 5 compétences: séparer MUST HAVE et NICE TO HAVE, (5) package: salaire, avantages, remote/hybride — soyez transparent, (6) processus de recrutement étape par étape. Ton: parlant, pas corporate. Longueur: 300 mots.
```

### Prompt 14 — Réponse automatique aux candidats (refus poli)
```
Rédige un email de refus pour un candidat [POSTE] qui a passé [X] étapes. Ton: reconnaissant pour le temps investi, 1 feedback concret (pas générique), porte ouverte pour le futur si le profil est bon mais pas pour ce poste. Maximum 100 mots. Pas de "nous avons le regret de".
```

### Prompt 15 — Plan de relance candidats (nurture sequence)
```
Élabore une séquence de nurturing en 4 emails pour des candidats "peut-être plus tard" qui n'ont pas été retenus mais dont le profil est prometteur. Email 1 (J+0): merci + restons en contact. Email 2 (J+30): actualité de la boîte + poste similaire si ouvert. Email 3 (J+90): article/intérêt partagé + check-in. Email 4 (J+180): nouvelle opportunité concrète. Pour chaque email: objet + 80 mots max. Ton: pas de newsletter, pas de marketing.
```
