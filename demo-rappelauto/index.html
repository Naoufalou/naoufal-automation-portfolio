Workflow n8n clé-en-main : rappel automatique 24h avant chaque rendez-vous, confirmation en 1 clic, relance si silence. Pensé pour les cabinets dentaires et médicaux.

-60%de no-shows
15 mind'installation
0 €de node payant

Comment ça marche

ScheduleTrigger (quotidien)
  └─ Google Calendar : lire les RDV de demain
       └─ IF : patient a confirmé ?
            ├─ OUI → Set : statut "confirmé"
            └─ NON → HTTP Request : envoi WhatsApp + email
                     └─ Telegram : notifier le secrétariat

Démo Python autonome (sans n8n)

Version script du même principe, exécutable partout :

$ python rappelauto.py --agenda agenda.csv --jours 1
